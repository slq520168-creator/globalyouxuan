GlobalYouXuan V1 正式上线版

手机部署最简单方式：
1. 解压 ZIP。
2. 把整个文件夹上传到你现有的静态网站托管空间。
3. 网站入口是 index.html。
4. 后台入口是 admin.html。

当前已经能操作：
- 五屏首页
- 手机/电脑自适应
- 中文、英文、柬文切换
- 四个核心方块
- 智能搜索
- 产品筛选
- 收藏
- 下单表单
- 后台添加/删除产品
- 后台查看订单与未匹配需求
- 导出后台数据

重要说明：
本版数据使用浏览器本地存储，因此同一台手机、同一个浏览器可以正常管理。
真正让不同客户的订单统一进入你的后台，还需要部署数据库或无服务器接口。
USDT、Telegram、邮件自动交付已经预留位置，但必须填入你的收款地址、Telegram机器人资料和邮箱服务后才能真实发送。
