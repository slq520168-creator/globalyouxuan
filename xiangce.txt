W001-个人相册版-99U

【你要解决的问题】
把手机里的照片做成一个在线相册，生成链接发给家人朋友，对方点开就能直接看。

【推荐方案】两个都免费，选一个做就行。

========================================
方案一：GitHub Pages（最稳定，推荐新手）
========================================

第一步：注册账号
1. 手机浏览器打开：https://github.com/
2. 点右上角 Sign up，用邮箱注册
3. 用户名建议用自己名字拼音（例如 zhangsan）

图文教程：https://docs.github.com/zh/get-started/start-your-journey/creating-an-account-on-github
视频参考：搜索“GitHub 注册教程”

第二步：创建仓库
1. 点右上角 + 号 → New repository
2. Repository name 必须填：你的用户名.github.io
   （例子：用户名是 zhangsan，就填 zhangsan.github.io）
3. 点绿色 Create repository

官方说明：https://docs.github.com/zh/pages/getting-started-with-github-pages/creating-a-github-pages-site

第三步：上传照片
1. 点 Add file → Upload files
2. 选择手机里的照片上传
3. 点 Commit changes

图文说明：https://docs.github.com/zh/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

第四步：添加相册页面（推荐）
1. 点 Add file → Create new file
2. 文件名输入：index.html
3. 复制下面整段代码进去，然后 Commit changes

<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>我的相册</title>
<style>
  body { margin:0; background:#f5f5f5; font-family: -apple-system, sans-serif; }
  h1 { text-align:center; padding:20px; margin:0; background:#fff; font-size:20px; }
  .grid { display:grid; grid-template-columns: repeat(auto-fill, minmax(150px, 1fr)); gap:8px; padding:12px; }
  img { width:100%; height:150px; object-fit:cover; border-radius:8px; background:#ddd; }
</style>
</head>
<body>
  <h1>我的相册</h1>
  <div class="grid" id="gallery"></div>
  <script>
    const photos = ["1.jpg", "2.jpg", "3.jpg"]; // 改成你上传的照片真实文件名
    const gallery = document.getElementById("gallery");
    photos.forEach(function(name) {
      const img = document.createElement("img");
      img.src = name;
      gallery.appendChild(img);
    });
  </script>
</body>
</html>

第五步：打开相册
手机浏览器访问：https://你的用户名.github.io/
把链接发给家人就能看了。

========================================
方案二：Cloudflare Pages（速度更快）
========================================

1. 打开 https://dash.cloudflare.com/ 注册并登录
2. 左侧点 Pages → Create project → Direct Upload
3. 项目名随便填
4. 把照片拖进去，点 Deploy site
5. 复制生成的链接发给家人

官方图文教程：https://developers.cloudflare.com/pages/get-started/direct-upload/
视频参考：搜索“Cloudflare Pages 上传教程”
