个人相册版 - 使用说明

你已经成功购买「个人相册版」。

这个方案的目标是：
把你的照片做成一个在线相册，生成链接后发给家人朋友，对方点开就能看。

推荐最简单的方法（手机就能完成）：

方法一：用手机自带功能
1. 打开手机「照片」或「图库」
2. 选中你想分享的照片
3. 点「分享」
4. 选择「拷贝链接」或「生成链接」（不同手机名称不一样）
5. 把链接发给家人

方法二：用免费网盘
1. 打开百度网盘 / 阿里云盘 / 坚果云（任选一个你常用的）
2. 上传照片到一个文件夹
3. 把文件夹设置成「分享」
4. 复制分享链接发给家人

方法三：想做得更像正式相册
可以使用 GitHub 或 Cloudflare 免费做网页相册（需要一点耐心，按官方提示操作即可）。

做完后把链接保存好，以后都可以继续用。

祝你使用愉快。
